# 🍽️ FoodCorner — Food Delivery Web Application

FoodCorner is a modern and responsive **food delivery website** designed to provide users with a smooth and visually engaging experience for discovering restaurants and food options.

The project focuses on a clean UI, responsive layout, restaurant discovery, search functionality, and interactive front-end components using **HTML, CSS, and JavaScript**.

## 🔍 How It Works

### 1. Restaurant Search

Users can search for restaurants or cuisines using the search bar.

The JavaScript filters restaurant cards dynamically based on:

* Restaurant name
* Cuisine type

For example:

```text
Search: Italian
        ↓
JavaScript checks restaurant names & cuisines
        ↓
Matching restaurants remain visible
        ↓
Non-matching restaurants are hidden
```

If no restaurant matches the search query, the website displays:

> No restaurants match your search.

---

### 2. Smooth Navigation

Navigation links use JavaScript to smoothly scroll users to different sections of the page instead of instantly jumping between sections.
